# 레퍼런스 정리

## 1. Open Extended Jungian Type Scales (OEJTS)

- 출처: Eric Jorgenson (2014), *Development of the Open Extended Jungian Type Scales* — https://openpsychometrics.org/tests/OEJTS/development/
- 라이선스: CC BY-NC-SA 4.0 (문항을 그대로 쓰지 않고 **원칙만 참고**)
- 수집: Firecrawl (`oejts_dev.md`, `oejts_main.md` — GitHub 제외)

### 배운 점

1. **문항 형식:** 두 문장을 양 끝에 두고 그 사이에서 고르는 양극 척도가 효과적이었다.
2. **개발 방법:** 278개 후보 문항을 자기 유형을 확신하는 25,568명에게 테스트해 구분력 높은 48개만 남겼다 (지표당 12개).
3. **지표별 난이도:** 구분력(평균 점수 차, 5점 척도)
   - E/I 최대 1.77, T/F 최대 1.67, J/P 최대 1.43 → 구분 잘 됨
   - **S/N 최대 0.75 → 가장 구분이 어려움.** 문항을 더 다양하게 만들어야 한다.
4. **잘 통한 문항 주제** (`oejts_top_items.txt`)
   - E/I: 파티 후 지침 vs 신남, 혼자 있는 시간, 듣기 vs 말하기
   - S/N: 현실 vs 가능성, "무슨 일이 있었나" vs "그게 무슨 의미인가", 현재 vs 미래
   - T/F: 감정 중시 vs 불편, 마음 vs 머리, 공감 vs 정의
   - J/P: 준비 vs 즉흥, 미리 계획 vs 막판 계획, 정리된 방 vs 아무 데나

### 우리 테스트에 반영

- 40문항 (지표당 10개), 7단계 응답
- 지표마다 좌우 방향을 절반씩 섞기
- 결과는 % 강도로 보여주기
