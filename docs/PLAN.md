# 나의 성격유형 테스트 (MBTI 스타일) — 계획서

> 작성일: 2026-10-12 · 상태: 초안

## 1. 한 줄 소개

40문제에 7단계로 답하면 **16가지 성격유형 + 지표별 성향 강도(%)**를 알려주고, 결과를 **공감 밈 카드**로 보여주는 웹 테스트.

## 2. 목표

- **정교하게:** "E냐 I냐"만이 아니라 *얼마나* E인지 %로 보여준다.
- **재밌게:** 결과에 "INFP가 답장 미룰 때 머릿속" 같은 밈 문구를 넣어 친구에게 공유하고 싶게 만든다.

## 3. 대상 사용자

- MBTI를 좋아하고, 친구와 결과를 비교하며 노는 10~30대
- 무료 테스트 결과가 매번 달라서 "진짜 내 유형"이 궁금한 사람

## 4. 핵심 기능

| 우선순위 | 기능 | 설명 |
|---|---|---|
| 필수 | 40문제 테스트 | 지표당 10문제, 한 화면에 5문제씩 8페이지 |
| 필수 | 7단계 응답 | 왼쪽 문장 ●●●○●●● 오른쪽 문장, 가운데는 "반반" |
| 필수 | 지표별 % 막대 | E 72% / I 28% 처럼 4개 막대 |
| 필수 | 유형 설명 | 별명, 특징, 강점, 주의할 점 |
| 필수 | 잘 맞는 유형 | 궁합 좋은 유형 2개와 이유 |
| 필수 | 밈 카드 | 유형별 공감 밈 3장 (직접 쓴 문구 + 이모지 디자인) |
| 선택 | 진행 저장 | 새로고침해도 답한 문제 유지 |
| 선택 | 결과 링크 공유 | 링크로 내 결과(유형 + %) 공유 |

## 5. 정교하게 만드는 방법 (레퍼런스 반영)

| 원칙 | 이유 (references/README.md 참고) |
|---|---|
| **양극 문장 문항** — "A ↔ B" 두 문장 사이에서 고르기 | 공개 성격검사 OEJTS 연구에서 가장 구분력이 좋았던 형식 |
| **좌우 방향 섞기** — 지표마다 절반은 왼쪽이 E, 절반은 왼쪽이 I | 한쪽만 계속 누르는 습관(응답 편향)을 상쇄 |
| **S/N 문항은 상황을 다양하게** | S/N이 가장 구분이 어려운 지표 → 그림 감상, 설명 방식, 미래 vs 현재 등 여러 장면에서 질문 |
| **점수 계산** — 각 문항 −3~+3, 지표 합계를 0~100%로 환산 | 강도 표현 가능. 50%면 "경계형"으로 안내 |
| **동점 처리** — 50%일 때는 가장 강하게 답한 문항 쪽으로 결정 | 결과가 항상 4글자로 나오게 |

## 7. 데이터

| 파일 | 내용 | 만드는 방법 |
|---|---|---|
| `app/data/questions.json` | 40문항 (지표, 왼쪽 문장, 오른쪽 문장, 방향) | 레퍼런스 원칙을 참고해 **직접 작성** |
| `app/data/types.json` | 16유형 별명·설명·강점·주의점·궁합·밈 | **직접 작성** |

- 공식 MBTI® 검사 문항은 저작물이므로 사용하지 않는다. "MBTI"는 The Myers-Briggs Company의 상표이며, 이 테스트는 **비공식 재미용 테스트**임을 화면에 밝힌다.
- OEJTS 문항은 CC BY-NC-SA 라이선스 → 그대로 번역해 쓰지 않고, 원칙만 참고한다.
- 밈은 실제 사진(저작권·초상권) 대신 **직접 쓴 문구 + 이모지 + CSS 디자인**으로 만든다.
